Windows Vista / 7

Copy Unicode Real Time Font Conversion Utility on your computer

Windows XP

Copy Unicode Real Time Font Conversion Utility on your computer
install the IskolaPotha Font (iskpota.ttf, iskpotab.ttf)


Linux - Ubuntu

Copy Unicode Real Time Font Conversion Utility on your computer

creat a folder named ".fonts" on home folder of your login.(/.fonts)
copy the True Type Font (iskpota.ttf, iskpotab.ttf) to the ".fonts" folder.
